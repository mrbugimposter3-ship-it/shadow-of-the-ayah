# Shadow of the Ayah: A Quran Reading Ninja Quest

A turn-based ninja RPG where every strike is powered by reading the Quran correctly. Covers all 114 surahs (6,236 ayat), starting with Al-Fatiha and Juz 'Amma.

**Play:** open `index.html` in a browser, or play online via GitHub Pages.

- Quran text: Tanzil Uthmani (quran-uthmani) and Saheeh International English, via api.alquran.cloud.
- Arabic font: Amiri (SIL Open Font License, see `OFL-Amiri-font.txt`), embedded.
- Music: original, generated live in the browser. No recitation audio.
